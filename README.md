# Orbite

Un petit vaisseau tourne autour d'un soleil sur trois orbites. Saute d'une orbite à l'autre pour éviter les astéroïdes, ramasse les cristaux, fuis les éruptions.

Espace, clic ou ↑ : orbite suivante vers l'extérieur (après la dernière, on revient au centre). ↓ ou clic droit : vers l'intérieur. Quand le soleil clignote, une éruption va brûler l'orbite intérieure. Les cristaux ramassés à la suite font monter le multiplicateur.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Orbite → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
